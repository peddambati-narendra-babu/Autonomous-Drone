Autonomous Drone-Based Disaster Management and Relief System
📌 Overview

The Autonomous Drone-Based Disaster Management and Relief System is an AI-powered UAV designed to provide rapid emergency response in disaster-affected and remote regions. The system integrates NavIC and GPS dual-navigation, AI-based path planning, and autonomous obstacle avoidance to ensure reliable and safe operation even in challenging environments.

The drone is capable of delivering essential medical supplies, navigating autonomously, and operating with minimal human intervention, making it suitable for disaster relief, emergency logistics, and humanitarian missions.

🚀 Features
AI-based autonomous navigation
NavIC + GPS dual navigation system
Intelligent obstacle detection and avoidance
AI path planning using the A* Algorithm
Geofencing and restricted zone compliance
Medical payload delivery with GPS tracking
Real-time autonomous decision making
Thermal and waterproof protection for harsh environments

⚙️ Working
The drone receives the destination coordinates.
Navigation is performed using NavIC and GPS.
AI calculates the shortest and safest route.
Sensors detect obstacles during flight.
The drone automatically avoids obstacles.
Medical supplies are delivered to the target location.
The drone returns safely after mission completion.
